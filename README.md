# EDID Reader

一款适用于 Windows 的 EDID 读取与可视化工具。

## 功能

* 读取当前连接显示器的原始 EDID
* 展示设备身份、色域、HDR、接口、VRR、时序、音频与原始数据
* 绘制 CIE 1931 xy 色度图，显示色域覆盖率、容积率、原色与白点
* 解析 HDMI 与 DisplayPort 能力，包括色深、TMDS、FRL、ALLM 与 VRR
* 导入和导出 EDID 文件
* 保存显示器数据，支持重命名和删除
* 导出信息图片与视频时序 CSV
* 支持简体中文、English、浅色、深色与跟随系统模式

## 使用

1. 下载并解压程序。
2. 运行 `EDIDReader.exe`。
3. 从左侧选择显示器，查看不同分类的信息。
4. 使用窗口右上角按钮刷新、导入、保存或导出。

支持导入 `.edid`、`.bin`、`.dat` 和 `.json` 文件。

## 数据位置

程序采用便携方式保存数据。显示器存档、设置与默认导出文件均位于程序所在目录。请将程序放在具有写入权限的文件夹中。

## 系统要求

Windows 10 或 Windows 11，64 位。
